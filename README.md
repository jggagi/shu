# 蜀（shu）

以《武林群侠传》的养成体验为启发，结合四川／蜀山元素的原创武侠修炼与生活养成游戏。先做 Web，后续视试玩结果考虑 Steam。

开发采用小步互动：**Codex 做一个可玩的 demo → 用户试玩拍板 → Codex 修订 → 更新决定与扩展计划**。
