# 柳岸光景：清晨、午后、黄昏与月夜

## 玩家可见的结果

底部增加清晨／午后／黄昏／月夜四个互斥按钮，默认仍为午后。清晨减少暖色、减轻柳影，并在远水增加薄薄空气感；黄昏改变暖光中心和强度，石岸偏暖、河水较冷；月夜降低饱和度与亮度，以蓝灰月色保持台阶和人物可读。同一原画、人物与环境动态一起受光，UI保持清晰；没有添加画中不存在的太阳、月亮或灯笼。

原「午后光／原画光」按钮随所选光景改名，可暂时查看原图光，再准确返回所选效果；点击其他光景会重新开启效果。菜单、对白和运动开关造成的视图重建保持选项。景动／静景仍控制同一环境相位，切换光景即时生效。

手动预览不推进宿主时辰、不花精力、不改revision与存档。现有养成钟只有卯辰巳午申酉，月夜只作美术预览，没有新增夜间规则，按钮悬停提示说明这一点。新局沿用当前光景选择，宿主进度照常清除；重启应用默认午后。
