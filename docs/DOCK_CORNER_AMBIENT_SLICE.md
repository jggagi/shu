# 柳岸小埠：环境动态

2026-11-13，X1 Fedora。用户要求增加环境动态。本轮继续[码头午后光](DOCK_CORNER_LIGHT_SLICE.md)的完整手绘样片，添加柳梢、布篷和船旁水纹；新动态观感待用户试玩。

## 画面与行为

- 柳树细叶有轻微随风变形，树干保持固定。背景中的柳叶和人物前方的柳叶遮挡使用同一shader、同一相位，因此动态与遮挡一致。
- 茶棚布篷的上沿固定，松弛的斜边微微起伏。放大原图发现茶壶藏在低布篷后，蒸汽上升会穿过篷布，故本片选择布篷动态，没有从木桌或罐子上凭空冒烟。
- 船尾与船头旁的两处水面各有两圈低对比椭圆水纹，缓缓扩散后淡出。两处[锚点](../assets/data/dock-corner-ambient.json)按原图标注在船身外的水面上，船、缆绳、木跳板与岸墙保持原画位置。

绘景局部变形与原水动合并在[同一shader](../addons/cultivation_mode/dock_corner_water.gdshader)，柳叶横移最大约2.3个原图像素，布边约0.78个原图像素；淡出范围外不改变纹理采样位置。[水纹shader](../addons/cultivation_mode/dock_corner_ripples.gdshader)是透明绘景层，再经过原午后光处理。沿用已有受控环境相位与原柳影缓慢频率，未使用独立shader TIME、随机事件调度或第二个养成时钟。

原「水动／静景」按钮改为「景动／静景」。静景保留当前场景和水纹，冻结各自当前相位；菜单和确认窗口也暂停，关闭后延续。人物位置、寻路、存档与行动仍由既有EngineSession管理，旧内容包和地图没有变化。无需新生图、素材采购、插件或依赖。
