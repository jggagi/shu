# 听雨廊完整改进规划 v1

日期：2026-10-07。状态：用户已授权完成 A–D／全部 P0–P2；本机实现、四个角色姿态素材、原生预览及新 Web／Windows 导出已完成，Web 输入复核通过。Windows 实机、设备听感与用户试玩仍待完成。用户要求「可以，还不够，一次规划这个场景所有的 improvement」；此前茶盏热气方向已获「可以」，现已接入本地候选。本文给出听雨廊这一场景的完整制作范围、批次与完工标准；用户随后以 `$tiered-coding` 要求「全部完成」，本文件清单成为本轮实施范围。

## 1. 最终体验

玩家在同一幅听雨廊画里，能感到师徒正在生活、天气正在经过、修行正在发生。

- 打开后短时间内能察觉人物和环境有生命；阅读对白时，注意力自然落回师徒。
- 清晨晴天、午后多云、小雨、黄昏各有可辨认的气氛；天气变化有过程，雨停有余韵。
- 茶盏、猫和少量可查看的器物让廊内有日常感；角色表演回应玩家实际行动。
- 连续停留仍舒服，安静的片段成立，声音和动作强度可调。

视觉顺序：师徒脸与当前行动 → 案上生活细节与猫 → 廊外山景与天气 → 辅助控制。环境、人物和 UI 的画风、线条、明暗及动作幅度一致。

## 4. 四批交付

### A：画面与节奏统一

范围：UI1、RH1、SO1、AC1 基础，及现有 EV4 的小幅校准。

交付：清楚的控制布局、一份全部效果的注意力规则、声音试听候选与已实现效果的强度基线。保留玩家正面反馈的猫位置和原画风格。

验收：主要人物与窗景有足够空间；看一阵风从起到落；对白开始后动作和声音都收敛。声音自然度得到具体试听反馈。

### B：师徒与廊内生活

范围：AR1、AR2、LI1、LI2；LI3 的首次出现与姿态衔接核对。

交付：眨眼／呼吸、修炼与请教关键姿态、茶气、猫点击回应。同一批整体进入游戏，比较静卧、空闲、行动、对白四种状态。

验收：玩家能明确感到师徒“在场”；修炼与休息有区别；热气看得清、摸猫有回应，人物脚点／手部／桌面接触稳定。

素材流程：先用现有主角、师傅、桌面与整场景做参考，只生成最小关键姿态小样，放回游戏检查身份和动作，再扩其余素材。实际生产依 `game-art` 的参考—小样—批量流程；规划轮不调用生成服务。

### C：窗外天气与声场

范围：EV1、EV2、EV3、EV4 完整复核、SO2、SO3 的环境部分。

交付：四组可对照氛围——清晨晴天、午后多云、小雨、酉时；窗光／山景层次／雨后湿色与对应声音。天气依现有玩家选择，时辰依真实行动。

验收：无需看标签也能区分；下雨、停雨、放晴各有连续过程；廊内暖色和窗外冷色协调，画面运动与声音一致。

### D：轻交互与完整收尾

范围：OB1、TX1、SO3 剩余、AC1 完整与 QA1。

交付：两件案上器物查看、少量环境／休息文案、原养成行动结果反馈收尾，以及完整试玩候选和版本说明。

验收：既能安静待在画里，也能发现少量可点的东西；既有修炼、师傅、Tea、Reset 流程完整。用户试玩反馈收敛后再决定保存到 GitHub／发布。

批次关系：A → B → C → D。各批都是一组可感知的结果，反馈主要调整强度、动作自然度与内容选择，后续沿同一总路线推进。

## 5. 全场景行为规则

| 状态 | 人物与猫 | 风／热气／山景 | 声音与交互 |
| --- | --- | --- | --- |
| 空闲 | 低频呼吸／眨眼、稀疏生活动作；猫可安静留场。 | 柔和背景流动，显眼变化轮流发生。 | 可听轻环境音，已批准的物件／猫热区可用。 |
| 修炼／对白／物件查看 | 当前主角或师傅表演优先，生活动作安静退让。 | 不启动新的抢眼事件，已开始过程柔和完成／收敛。 | 环境音降低；避免多重前景占用与重复结算。 |
| Static | 保留人物和居民的稳定姿态，禁用生命回应。 | 冻结运动和相应机会；保持已批准的时辰／天气主动过渡合同。 | 环境音渐静；声量／天气／原养成 UI 仍可控制。 |
| 恢复 Dynamic | 从定义好的稳定状态继续，避免跳帧／位置跳变。 | 延续冻结位置与调度边界。 | 不补播过时声音。 |
| 切换到 Tea | 主廊演员／器物随场景隐藏。 | 主廊动效不穿入 Tea 画面。 | 听雨廊声音退去，热区隐藏，遵守 Tea 既有返回门。 |
| Reset | 重置本轮演出、猫事件与交互呈现历史。 | 清空余水／过渡历史，回宿主初始状态。 | 清待播放声音与失效回调，保留当前声音选择；原数值结算仍归宿主。 |

“一次主要变化”由场景自己的既有 adapter 协作实现。先使用场景内简单注意力输入与冷却，第二个实际场景需要同一行为后再考虑共用接口。

## 6. 完工验收地图

- 首次体验：打开后很快能察觉生命感；继续真实停留有机会遇见猫和稀疏远鸟。首次时机和出现密度是可调参数。
- 行动体验：修炼 → 实际结果 → 请教师傅 → 选择 → 休息；动作、文字、数值和时间对应，取消与低精力拒绝正常。
- 天气体验：晴 → 小雨 → 晴，检查过渡、细雨、积水／落滴、余雾／湿色、声音退去、猫天气退场；通过真实休息进入酉时检查灯火。
- 发现体验：摸猫／物件查看能短暂回应，关闭后回原行动；不会错入 Tea 或透露后续内容。
- 注意力体验：真实师傅对白、修炼、Tea 阅读时环境退让；人物和文字无遮挡。
- 静态与重置：各类运动、机会、声音与热区遵守矩阵，恢复无突变／补播，Reset 无残留。
- 显示与输入：1152×720、960×600；不同宽高比的等比缩放，鼠标、键盘、焦点、字体与音量提示。
- 声音：本机实际扬声器／耳机与 Web 玩家开启路径分别试听；设备输出、混音数据、玩家听感分别记录。
- 稳定性：至少一次连续 10 分钟真实久留，观察频率、重复、突变和音频循环；这项是体验观察，不替代长期性能验收。
- 目标平台：Mac 本地只是开发证据；Web 与 Windows 各自完成实际用户路径。自动检查、渲染、浏览器操作、用户认可独立标明，未执行则保持未验证。

## 7. 执行与制作依赖

- `game-painted-scene-build`：构图、天气、光色、热气与风等环境制作。
- `game-ambient-life-build`：真实栖息点、猫／鸟、稀疏时机、注意力退让与轻回应。
- `game-cultivation-build`：行动表演、人物／器物交互与原宿主行为。
- `game-art`：新人物姿态或必要背景图层，保留风格参考、来源、许可和 hash。
- `tiered-coding`：根代理定批次、接口与验收，真实 Luna 执行已决定的有限素材、代码或只读核对任务。

现有 skills 可承载这些批次。`shu-binding.md` 的“听雨廊尚未复用”及 checkout／远端 snapshot 是早于当前实现的历史描述，本规划以刚核对的 active 源码为准；方法文件的维护另记，不据此创建不存在的 addon。
