# 码头：少量居民的差异与连续行程

适用于小型画景里的路人／常住动物；不是人群模拟或NPC剧情系统。基线见[行人任务卡](../../../../docs/DOCK_CORNER_CAST_SLICE.md)和[生趣任务卡](../../../../docs/DOCK_CORNER_LIFE_SLICE.md)。

## 差异先在小窗口成立

柳岸只保留两名行人与一只猫。两人复用同一成人骨架，但书生较修长，有青灰衣、巾帽、小册，背手或捧册望水；脚夫较宽厚，有麻衣、斗笠、篓、背带，前倾扶篓或停步歇肩。体型、轮廓、道具与姿势组合比只换颜色／速度更容易辨认。原玩家和茶商实例保持原样；没有因此新增独立脸模或人物故事。

腿部继续用原步态，按实际行走距离采样；上身目标在腿部采样后处理，检查脚底和手部目标。配件跟随对应骨锚点，身体缩放与锚点变换一起处理。不能靠肩部大摆动掩盖手够不到背带。本片首次背手目标超出可达范围，调整到手臂可达区域；没有手指骨，不能声称精细抓握。小物件按材质合批降低节点数量，但节点减少不是性能实测。

## 路线要验证实际开始移动

[路线配置](../../../../assets/data/dock-corner-life.json)与[表现控制器](../../../../addons/cultivation_mode/dock_corner_life.gd)分开。选干岸短路径，起点、方向、停留时间也要看；不能只校验路径点有效。

本片一名路人起始距离35时，进入玩家55逻辑像素让路范围，长期不走；改起始距离130后检查两人开场实际位移。55与130是案例调参，不是新片默认。近玩家停步是视觉礼让，不是完整碰撞避让。只加路人前，先看玩家出生点、物件接近点与居民初始点的相互关系。

猫只有真实茶棚前干岸Place路径，没有可用雨棚能力，不凭水面就顺便加鱼。多姿态图集按各帧接触pivot、有效宽度和方向保持尺度；移动距离驱动步态，坐下／张望是明确停留姿势。猫进入人物3D深度通道，避免2D覆盖层压住前方人物。

## 保存行程，不保存第二套玩法

本片控制器由View持有，UI重建保留行程；每次重建Walker只绑定展示节点，不能重置居民。新run才清理表现状态。机会由固定种子和时间边界控制，不逐帧随机触发，不把这些表现字段加入宿主存档。

Busy／静景／菜单让居民在当前位置切到安静站姿或坐姿，保留原路程与机会时钟；恢复后继续，不回出生点，也不把迈步停成悬脚。前台动作拥有自己的占用与暂停合同，不能直接借居民暂停逻辑。详见[城镇方法中的三个合同](../../../../docs/PAINTED_TOWN_PRODUCTION_METHOD.md#三个需要显式写下的合同)。

检查开场实际位移、路径端点、玩家靠近、交谈、菜单、静景往返、UI重建及重开；至少看一次人与猫交错、左右方向和暂停姿势。固定种子便于复现，但用户是否喜欢密度和姿态仍要单独记录。
