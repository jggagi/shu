# 当前事件驱动的底部头像对话

在已有宿主中新增或调整人物头像对白栏时读取。本例范围是独立码头及其原师徒事件，没有把其他入口改成同一UI。见[任务卡](../../../../docs/DOCK_CORNER_DIALOGUE_SLICE.md)、[DockModeView](../../../../addons/cultivation_mode/dock_corner_mode_view.gd)和[UI配置](../../../../assets/data/dock-corner-dialogue-ui.json)。

## 同一事件决定头像和文字

- 从唯一Session的当前`event_view()`读取speaker、显示名、台词、选项和可用原因；通过稳定speaker ID查头像。不要在UI维护另一套对白索引或按按钮次数切头像。
- 无speaker时切到旁白样式，清掉上一头像。缺头像时显示明确的无图样式或在授权内制作，不借另一位人物的图改名。
- 选项调用原host方法、保留原条件、费用、禁用原因和操作身份；本片包含run、event、node、sequence、option。继续保留原run／revision捕获，旧按钮回调不能推进新run或新节点。改排版不重写这些协议。
- 事件结束收起整栏。旁白与无选项的继续仍是当前节点展示，不新加剧情节点或结算入口。

## 覆盖画景的层级与占用

本片底栏加在全屏UI根下，隐藏旧事件小面板而不缩画景；位于菜单／确认遮罩之下，UI不受昼夜世界调色。按钮保留实际Control输入，不能让画景热点穿透点击。注意原底部工具栏、安全边距、长台词、选项与说话人切换时的高度变化。

当前调参为逻辑1440×900根、238高底栏、158×190头像；1152×720及960×600实际检查通过。数值只适合本片，不是任意窗口、手机或本地化排版已验证。迁移时检查目标窗口与最大实际文本，不机械复制尺寸。

动作进行中的对白仍服从原表现门禁：投石出手／飞行时仅显示阶段提示，落水后才展示原结果，收势前禁继续。文本已在host产生不等于应该立刻提前显示。展示不能再调用一次结算，也不能用环境静景开关替代动作的暂停合同。

## 头像生产与裁区

先查当前人物资产。主角和师父复用既有原图；本片男茶商没有对应图，先从当前模型导出身份参考，再以原人物画作为风格参考，使用已选百炼标准模型制作。新图的准确输入与参数见[来源](../../../../assets/art/dock_dialogue_portraits/source.json)。制作新图仍走[game-art](../../game-art/SKILL.md)，不能因本参考存在就自动生成一批角色。

离线SubViewport取景时，未设置UPDATE_ALWAYS曾得到全透明图；先检查渲染图有效再发给生图模型。原图有意外底部文字框，本片AtlasTexture裁到文字框上方，源PNG保持。裁区需要保留完整脸部与服饰识别；身份错误或五官损坏应退回素材阶段，不能用裁区掩盖。图上的假文字不能进入真实对白。

## 有用的回归路径

茶商选择→当前台词→旁白→关闭；主角／师父轮换；禁用选项及其原因；菜单覆盖与返回；投石出手前／落水后／收势；读档／重开清理。核对头像ID、姓名、文字与同一当前节点一致，操作造成的资源变化只发生一次。展示检查可以比较完整宿主状态，确保截图或换头像不改变玩法。

原生UI检查、Web导出、HTTP文件一致、浏览器真实操作和用户美术认可分开记录。记录所测源码及dirty状态；不要把任务卡里交付时“待认可”删除，当用户反馈后补上反馈及其范围。
