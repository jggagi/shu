# 支线事件链：养成模式内的接入

用于 tea 等多阶段支线。活动、人物互动或固定场景热点进入事件；事件可以切换固定背景、调查物件、阅读文书或呈现短回忆，作为养成模式内的支线持续进行；整条支线完成后才返回养成主界面。阶段完成、关闭物件浮层和普通失败均不触发主界面返回。通用事件链仍为设计；shu A/B 的宿主适配与物品中心交互已实现，后续未实现。

## 最小能力与状态

| 能力 | 接入方式 | 状态要求 |
| --- | --- | --- |
| 分阶段推进 | quest/stage ID、宿主前置与完成旗标 | 修炼、休息、次日和退出支线不清空已提交进度 |
| 触发 | 菜单、对话、热点统一路由已登记活动 | 进入与结算时重查条件；不编造未批准的日期门槛 |
| 调查物件 | 固定场景热点绑定稳定 object ID | 描述随已知信息变化；重访不重复结算 |
| 阅读 | 按内容需要登记 document cue；普通查看直接提交 | 仅明确 await_ack 的叙事 cue 等待继续；普通物件无确认；后期资料受条件限制 |
| 场景/短回忆 | 登记 profile/memory cue，保留返回上下文 | 不改变主角身份或自动推进养成时间；关闭子视图恢复支线场景，整条完成后恢复养成主面板 |
| 一次完成 | 宿主白名单行动提交旗标与必要结果 | save/run + quest + stage 唯一键，换会话也不重复发奖 |

继续用 `say / choice / cue / end` 四类节点。表现 cue 不修改剧情旗标；明确 await_ack 的叙事阅读等待玩家继续；普通物件直接查看，取得线索与完成阶段由明确宿主行动提交。关闭物件／阅读面板保留已提交线索及支线占用，不完成条件未满足的阶段；若宿主明确允许中断／放弃，按该独立合同处理，不将 Escape 默认映射到返回主界面。

进度包含旗标、事件节点、已取得线索和返回上下文。正文阅读位置与线索取得须分开定义。存档落地时与养成状态/回执一起保存；尚无存档时只承诺当前运行内保持。新周目/明确重置与普通休息、次日和退出事件必须区分。

## 一轮验收

选定一个阶段，列出可见线索、不可提前透露的信息、场景/物件和返回位置。交付“进入支线 → 调查/阅读／支线内行动 → 阶段完成并留在支线”的小片段；完整支线终点实现后，再验“整条完成 → 返回主界面”，再按试玩反馈接后续阶段。

检查早期入口无剧透、两杯可点、物件/阅读浮层可收起且留在支线、未完成与非终点阶段完成不能返回主界面、支线内歇息、重访不重复结算、已完成阶段不重发奖励、休息/次日保留进度。存档实施后再验证恢复节点与返回场景。完整结尾额外核对同一茶杯 ID、后期描述、添茶沉默与标题变化。
