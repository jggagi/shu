# 成都首街：建筑与路面接缝修正

客户端日期2026-11-12，America/Los_Angeles。用户反馈「建筑物和地板衔接有点怪，不太真实」，本轮针对原18屋的基础与路面空间关系修正，保留已认可的画稿、街段密度、连续镜头、通路和玩法；新观感待试玩。

## 原因与实施

0.8.2把完整屋景摆在固定斜面，再给底边补水平暗条。画稿内的基础V形透视与实际52度相机的水平地面不一致，图中若干底边实际仍高于路面；两条分离的边缝和较粗路面石板进一步强化剪贴感。旧的数学地面条不能证明画中台基本身接触地面。

本轮0.8.3继续使用[同一首街入口](../scenes/demos/cultivation_engine_chengdu_finished_street.tscn)，由[接地适配](../addons/cultivation_mode/chengdu_grounded_street.gd)继承原整街helper，限定修正：

- 按原图每屋左／前／右三个基础接触锚点，对应原建筑矩形SW／SE／NE真实地面角；台基底边统一落到0.033米的水平表现面，原622障碍和人物行走坐标不变。
- 屋顶保持原画网格；墙面和台基采用24像素分区的纹理网格，向基础角连续变形，并把接触V折线作为真实网格边，避免只插值跨过弯角。
- 移除原10条分离的平行排水深缝，保留36条更窄的墙脚软接触。加36段宽0.32米、向路面渐隐的小石板过渡，复用原已登记的铺地PNG；共用既有太阳的Compatibility阴影接收方法，无新灯或全局光照改动。

参数与原纹理来源见[表现布局](../assets/data/chengdu-grounded-street-layout.json)。未修改原屋景／市场／铺地PNG、原地面绘景及深度偏移、相机、导航、剧情／交易／养成或EngineSession。13处植物、9盆、五面布幌和一处茶烟保持。仍为固定视角2.5D，不是逐窗重建的完整3D建筑。

构建用户目录`shu-chengdu-grounded-street-20261112`、SaveStore仍为`user://chengdu_finished_street`，本机新预览[18875](http://127.0.0.1:18875/)已启动；原18874冻结包与原存储保持，不自动迁移不同端口的浏览器档。
