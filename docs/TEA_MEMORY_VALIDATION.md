## 首次排版问题与修正

真实 Web 进入柜中日记时，容器在还没有给自动折行 Label 分配宽度前，计算了 1907px 的对白框最小高度，遮住人物并挤走继续按钮。早先的全流程测试在旧回调检测时重复呈现，意外修正尺寸，掩盖首次进入问题。

已改为固定场景内的平面对白布局：先清空文字并分配宽度，再写入原文，以真实字体最小高度容纳换行。短对白用较大字号，长记录保留完整文字。专项新增首次进入、未重复呈现时的对白／按钮边界检查，原生截图也实际核对人物遮挡。初始失败日志保留；通过结果以最终日志为准。

真实 Web 交付停在 F「你是谁？」第一页，继续即可体验相识、等待、喝茶与暮色。临时测试视口已恢复默认，刷新将重新开始。
