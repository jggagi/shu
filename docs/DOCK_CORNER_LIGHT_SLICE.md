# 柳岸小埠：午后光照对照

2026-11-13，X1 Fedora。用户反馈独立码头的画风比此前更好，希望增加光照。本片沿用[独立码头](DOCK_CORNER_SLICE.md)的完整画稿、构图、人物、地图、碰撞和养成内容，只调整表现。新光照尚待用户试玩认可。

## 玩家可见变化

- 大片柔和暖光落在石岸、台阶和布棚，保留原图的石纹、瓦片和笔触；茶棚檐下增加少量偏冷的暗部。
- 从原画柳树区域取样叶间明暗，做柔化与局部投影，在柳树右侧石岸形成缓慢变化的斑影。接收范围由该画面的石岸位置约束；不是新生图、旋转贴图或遍地重复亮斑。
- 原3D人物使用较冷环境光与较暖主光，再与底画、前景一起经过同一局部画面处理。关闭效果时恢复原人物灯光参数。
- 底部「午后光／原画光」可随时对照，不重建场景、不取消路线、不改变Session状态。「水动／静景」控制原受控相位，菜单、确认和静景均冻结。菜单重绘延续光照选择；换一局按原规则清理相位。

[光照shader](../addons/cultivation_mode/dock_corner_light.gdshader)只覆盖绘景矩形，UI与留白不受世界光照影响。它保持原画光影并做有限明暗调整，不提供可旋转太阳、真实水体反射、全场景物理投影或昼夜系统。固定午后光是本次美术对照，未将它接成新的时辰权威。
