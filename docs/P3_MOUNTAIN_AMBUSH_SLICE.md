# P3a · 山道遇袭

本页封存 **18816 首轮战斗候选**的表现、构建与验收。后续人物造型、近看入口与新试玩见[人物修订切片](P3_AMBUSH_CHARACTERS_SLICE.md)，不把本页旧模型来源或检查计数用于新包。

客户端日期：2026-10-24，America/Los_Angeles。用户本轮明确选择轻量小队方格回合制，并授权“两人对三人、击退、打断、保护目标”的本地可玩切片。玩法已实现；最终验证、试玩入口与限制见本页后续记录，用户认可仍待试玩。

## 玩家可观察的范围

- 江砚秋与沈听岚对持棍客、刀客和弓手；药篓为独立受保护物件，不是第三名队员。
- 一张 9×7 紧凑山道，每人每轮可移动一次、出招一次，先后自由。四邻接路径，山石、人物与药篓阻挡通行。
- 松风剑近身攻击；江砚秋的回澜剑击退两格并改变本轮攻击位置，遇障碍追加碰撞伤害；沈听岚的截脉指打断敌人本轮移动和攻击；守势减少本轮每次受伤。
- 敌人先显示实际将攻击的格子。击退改变其出手空间并破坏进步；打断取消本轮行动，没有临时隐藏换目标。
- 护住药篓四轮，或击败全部敌人获胜；药篓毁坏或两名队员均倒下失败。撤离计本场失败。
- 胜败页可重试，或返回同一 Session 的集镇，继续原有返回师门、听教、五剑与复命。每场结束结算一时辰，无永久属性奖励，局内 HP 每场独立。

地图、HP、伤害、移动距离、四轮目标、招式名与表现都是本切片实施参数，待用户试玩调整，不因此成为整款游戏的最终规则。新增文字仅为机制连接与战况，不新增主线或支线原稿，不改写历史剧情。

首片使用固定战斗配置，尚未把养成剑术数值、已学武学或战前配招映射到战斗；该联动留在后续连续体验。本片先验收空间、控制和保护目标本身是否成立。

在 **X1 桌面内**打开 [18816 网页试玩](http://127.0.0.1:18816/)。原生独立窗口也已启动，运行已验证的同一导出PCK。新原生 custom userdir 为 `shu-mountain-ambush`，存档子目录独立；网页18816与旧18812–18815隔离。初次网页加载含约114.5 MiB资源。

```bash
cd /home/x1-lite/games/shu/.local/worktrees/mountain-ambush
godot --windowed --path . res://scenes/demos/cultivation_engine_v06_mountain_ambush.tscn
```

