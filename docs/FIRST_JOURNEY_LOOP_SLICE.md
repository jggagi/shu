## 试玩

1. 向画中的师父听教，读完对白并选择调息或自行练习。
2. 前往后山，任练一套剑法，可用原画人像修习，也可点击「进入练武场」在3D场地完成五剑组合演练；收息后回廊。多练一次可将剑术练到20，使本次战斗的江砚秋体力由22增加至26；每次仍花22精力、一时辰。

4. 两人护药：守住四轮或击败全部来敌获胜；药篓毁坏、两人倒下或主动撤离记为未完成护送。本场结束一次结算一时辰。
5. 回到集镇，走近返山石阶，在听雨廊点师父或「此行复命·完成本章」。按真实经历显示结尾，可保存此行、继续修行或确认重开。

存档、读档、语音和重新开始在右上「菜单」中；战斗中的声音、景物、相机和撤离在「设置」中。Esc收起菜单；终局返回集镇仍直接显示。

往返各花一时辰；行走、阅读和思考免费。没有现实倒计时。胜败都能走完本章。同一章只记一次山道经历，想体验另一结局需新开局；通关后继续养成和游历不会改写旧结局。
