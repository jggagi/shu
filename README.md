# 蜀山行记 · Web 试玩

[主入口](https://jggagi.github.io/shu/)现为 `0.1.18-five-sword-manuals`：听雨廊 → 后山 → 选择剑谱 → 修习 → 返回。松风、听雨、回澜、燕掠、叠峰五本原创剑谱，每本两式，按逐谱修习遍数交替呈现。换谱与普通往返免费；修习仍为精力 -22、剑术 +10、时间 +1 时辰。只有宿主 DemoState 结算；Tea／Busy 门保持。

沿用原始江砚秋美术及 Godot 原生 2D 骨架，人物体型／透明度固定；当前为站定修习，用户动作自然度认可尚未完成。逐谱遍数随当前运行保留，刷新／重新开始清空，没有磁盘存档。

这是已验证本地运行包的发布；源工作树仍有未提交修改，不宣称 base commit 包含本版全部源代码。所选源码和所有运行文件 SHA256 见 build-info.json，来源见 provenance/，许可证见 licenses/。没有合并源码 main。
