## 同一动作与原创角色

沿用 `assets/data/sword_mocap/source/02_09.amc` 与 `02.asf`，CMU 原始 120 Hz 取隔帧，60 Hz、517 样本、8.6 秒，时序不变。所有骨骼与根位移统一缩放 0.70；不逐帧改变骨长或人物尺度。Q 比例来自体积化头部、手和服装几何。

既有原创角色参考为 `assets/art/v2/jiang-yanqiu-v2.png`：深棕高马尾、浅蓝发带、暖棕眼睛、象牙白衣袍和蓝色交领。参考只有上半身；本次完整修习服装是原创延伸，尚不能视为最终造型。角色是完整 3D 体积，不用正面贴图在背转时压扁。连续衣袖在肩／肘／腕蒙皮；衣摆分片随腿姿势变形，避免深蹲仍像硬壳。材质采用高粗糙度、固定顶点色变化、细缝线及2.8 mm蒙皮墨色轮廓；水墨风格完成度需实际判断。

剑是自制道具，刚性绑定右手；CMU 没有剑身标记。源动作包含单手挥剑，保留源右臂和右手旋转。仅在左手自然靠近且可达时做轻微两骨 IK，保留源手腕／手旋转与肘部方向，不强制全段双手持剑。

脚步只识别低位、低水平速度的停稳窗口，用五帧平滑过渡固定脚趾接触点；保留捕捉中的足部旋转与其余迈步。没有全身物理或衣料模拟，不宣称解决所有鞋底穿插。该动作也不是经考证的中国剑法，源背转角度和非闭环限制沿用灰模研究。

## 重建入口

在匹配的 Godot 4.7.2／Blender 4.5.9 工具环境中，先构建模型，再渲染、打图集和独立 Web。复用已版本化的 CMU 原始文件，不需要购买或下载动作：

```sh
blender --background --factory-startup --python tools/sword_jiang/make_study.py -- --repo "$PWD" --output /path/to/rebuild --mode build
blender --background --factory-startup --python tools/sword_jiang/make_study.py -- --repo "$PWD" --output /path/to/rebuild --mode render
godot --headless --path "$PWD" --script tools/sword_jiang/pack_atlas.gd -- /path/to/rebuild/render "$PWD/assets/art/sword_jiang"
python3 tools/sword_jiang/build_study.py --output /path/to/stage-and-web --godot /path/to/godot
python3 tools/sword_mocap/serve_preview.py --directory /path/to/exported-web --port 8792
```

本机外部构建需按 workstation 约定先检查卷，再通过 `agent-dev run --` 执行；绝对路径只记录证据，不成为跨机运行依赖。字体已有独立 OFL 子集；仅 UI 文字变化时才使用 `rebuild_font.py` 和经 SHA256 校验的原字体重建。


## 美术方向反馈与研究暂停（2026-10-11）

用户明确反馈当前三维角色「不好看」，要求保留像3D一样准确的动作，同时驱动生成出来的精美图像。当前角色外观未获认可；服饰几何候选停止继续制作，已生成研究文件与旧试玩保留。该服饰候选只有模型构建和抽帧预览，没有完整序列、正式Web导出或用户验收，不应与上文已完成的v1检查混淆。

下一项待验证提案是离线图像驱动动画：已认可的3D动作提供动作视频／骨架控制，既有江砚秋全身原画提供身份和画风参考，再以时序模型生成短片并检查脸、衣服、手、剑和背转。官方Wan2.2 Animate和ComfyUI Move工作流支持参考角色图与动作视频，但这不保证生成帧严格服从3D几何。本项目尚未安装该工作流、运行推理或验证Q版持剑适配；不将它视为已选路线。先以2–3秒背转加斜劈片段验证，不扩展五本剑谱。零付费探索与购买另行确认保持。
