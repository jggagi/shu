# 单招式图像动作任务卡

复制本卡为该招式自己的任务卡后填写。每张卡只覆盖一个招式或一个明确变体；适用于单手剑、第二段剑法、双手棍等不同器械。没有证据的内容写“未知”并说明原因，不要把推测写成已核实事实。帧率、时长、分辨率、采样方式和镜头参数按本招式实际输入填写，不使用其他样本的数值作为默认规则。

## 1. 标识与范围

- **shot_id：**
- **招式名／器械类型：**
- **版本／修订日期：**
- **制作路线：**（生成图像时序／固定三维模型直接RGBA渲染／已有合法帧包；复用当前已确认路线）
- **组内计数：**（如属于多套，写明总数、是否含已有基线及本卡对应的稳定clip ID）
- **本卡范围：**（一句话说明仅覆盖的动作段、变体和不包含的内容）
- **当前状态：**（提案／素材核验／待授权／制作中／本地处理／集成验证／待试玩／已验收／暂停；注明日期）
- **对应角色与目标：**

## 2. 角色参考、来源与使用许可

- **角色／外观参考路径或受控 URI：**
- **文件 SHA-256：**
- **固定模型保护项（如适用）：**（原始网格／UV／纹理／权重／相机／握持／材质的基线；动作可变部分与实际结构检查）
- **作者／提供者与来源记录：**
- **许可状态及证据：**（已核实／待核实／未知；记录允许的本地制作、衍生、游戏内使用与发布范围）
- **本次实际获准用途：**
- **是否需要上传：**（否／是；若是，写明文件及哈希、接收方／服务、用途、授权证据、允许费用范围与实际费用。费用或上传状态未知时如实记录）
- **服饰、发型、体态及需保持的角色识别点：**

## 3. 器械、握持与动作意图

- **武器／道具：**（类型、形制、长度或相对人体比例、可见方向）
- **握持约定：**（左／右／双手；每只手握持位置、前后手关系、手掌朝向、接触点与动作中是否换手）
- **动作意图：**（对手、方向、重心和预期力量感；若只是视觉演示，注明）
- **器械与手、衣袖、发带等的遮挡／接触关系：**
- **需要逐帧保护的细节：**（例如剑刃／剑尖、棍端、握柄、手指、飘带或细发）

## 4. 动作参考与处理记录

- **三维／真人／其他动作参考来源：**（来源、资源标识或 URI、作者、SHA-256、许可状态及证据）
- **参考素材规格：**（实际画面尺寸、时长、帧率、方向、镜头、编码或格式）
- **本招式节奏：**
  - **起势：**（动作描述及实际时间点／区间）
  - **发力：**（动作描述及实际时间点／区间）
  - **收势：**（动作描述及实际时间点／区间）
- **完整动作时长／帧率／帧数：**（分别记录源输入、处理后素材；注明时间基准及任何删帧／抽帧）
- **播放意图：**（单次动作或真实循环；循环需记录入点、出点及首尾连续性检查。未验证连续性时不要标为循环）
- **待机／起剑衔接／回位合同：**（待机与动作入出点、真实支撑脚、位置／速度／朝向／手剑连续性、是否需要短回中性过渡）
- **组内差异证据（如适用）：**（步型、躯干、剑尖／手腕轨迹与节奏；数值差异和实际观感分开）
- **处理日志：**（抽取、重定向、缩放、镜头／背景统一、道具绑定或其他处理；逐项记录工具版本、参数、输入输出哈希和证据路径）
- **已知动作偏差：**（参考动作与目标动作、手部／器械关系、脚步或身体朝向的差异；不能证明逐点匹配时明确说明）

## 5. 制作任务、复用与成本边界

- **本地渲染工程与设置（如适用）：**（源工程、渲染器／版本、透明输出、分段任务和断点续做收据；合法复用需同时匹配模型、材质、相机、光照、姿态及渲染依赖）
- **是否使用生成服务：**（否／是；未执行与已执行分开记录）
- **服务、模型／版本、模式、任务 ID：**
- **输入文件及哈希：**
- **提示词、seed、生成参数与输出规格：**（保存原文或指向受控记录；未知项注明）
- **实际上传授权与目的地：**
- **预先允许的费用范围／上限：**
- **实际费用与账单证据：**
- **中间结果复用记录：**（源输入、模型、预处理、工具版本与区域配置的依赖；已有结果路径及实际复用情况，不把未实现的缓存写成已完成）
- **生成结果来源核实程度：**（独立核实／用户报告／未知；不可把用户报告补写成已独立核实）

## 6. 画面范围、站位与安全留边

- **目标场景及版本／来源：**
- **站位／脚底锚点：**（场景坐标或可复核的相对位置）
- **接触与位移策略：**（站定／跨步／蹲身／腾空的区间、支撑脚、舞台基点、真实身体位移与落地；避免把腾空帧拉回地面）
- **人物目标高度或占舞台比例、整体缩放与遮挡关系：**
- **镜头朝向／角色朝向：**
- **全动作包围盒：**（检查整个动作而非单帧；记录人物与器械的最外边界及坐标基准）
- **边缘留白：**（四边分别记录实际像素或比例；另记录剑尖、棍端及其他可能伸出的部位。注明最紧张的帧）
- **裁切、源片模糊或留边风险：**
- **场景对齐／落脚／遮挡实看证据：**

## 7. 透明边缘与局部保护

- **使用的原始透明度／抠像方法及版本：**
- **处理区域：**（坐标基准、区域形状、覆盖帧段、边缘过渡方式及对应配置路径）
- **保护区域：**（剑身、剑尖、棍端、握持手、发带、细发和其他易误删内容；记录如何逐段核查）
- **RGB 与 alpha 的变更范围：**
- **逐帧或关键帧审阅范围及结果：**
- **发现的白边、残影、脏块、漏擦、误擦及修正证据：**
- **自动检查与人工观看分别由谁／何时完成：**
- **本段生成／修整／检查耗时及返工原因：**（实测与估计分开，供后续批次统计）
- **仍未解决的抠像局限：**

## 8. 场景融合与呈现

- **接地方式及落点依据：**
- **场景调色／时辰天气适配：**
- **纸感／笔触／材质处理及强度：**
- **人物与场景的颜色、墨线、边缘和亮度目标：**
- **保持动作、几何、锚点与时间不变的检查：**
- **实际宿主接入（如适用）：**（结算方、资源预检、真实receipt、action_id、完成／返回通知及正式Static语义；不直接搬入审阅控制器）
- **包大小、加载时间、同时驻留纹理与帧耗：**（记录设备、测法与实测值；活动纹理引用、整包网络下载和尺寸估算不等于实测内存；未测项写未验证）
