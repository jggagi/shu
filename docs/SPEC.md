## 养成画面的视觉要求

已查看参考截图：中央固定背景，主角与师傅在前景交谈，周边显示人物状态／日期／养成信息，底部承载对话。借鉴的是画面组织和互动感。

- 固定场景作为画面主体；人物、状态和对话随行动更新，师傅互动保持在同一养成场景中。
- 宋式建筑、器物与服饰气质；中国画的留白、山石竹木和克制用色；主角与师傅为有表情的 Q 版人物。
- 信息可读、交互区域明确。面板比例、人物位置、字体大小与色彩细节由 Codex 根据试玩反馈调整，再由用户拍板。
- 后山独立环境实验的晴天加入太阳（2026-10-06 用户要求）；随真实养成时辰呈现位置／暖色变化，太阳构图、大小与当前表现已获用户试玩认可（同日「不错 我喜欢」），不影响养成数值。
- 后山的猫采用与环境、主角统一画风的可爱大橘猫，能够回应玩家互动，也能自己玩（2026-10-06 用户明确要求，D036）。本轮提供点击摸摸与短暂自娱，不影响养成数值；水彩橘猫外形已获用户认可（2026-10-06，D038），具体动作强度与节奏继续按试玩调整。
- 用户提供的三张概念图已原样保存在 [概念图索引](concepts/README.md)。当前按「听雨廊」概念分层制作背景、江砚秋／叶知闲、桌案和纸木面板，运行素材与参考原图分开；原图排除于游戏导出。用户认可这套美术风格；具体素材、构图与本轮动态强度继续供试玩评审。

首场景当前美术切片采用概念图「听雨廊」；画面标题暂用「蜀山行记」，不据此改仓库名或锁定最终发行名。场景名称、屏幕比例、面板尺寸、具体宋式元素属于排版提案，尚未拍板。美术的宋式方向不额外确定故事的历史年代。

## 首场景需要支持的复用方向

先用一个场景检验：行动选择、短对话、时间与养成状态的可见反馈。具体属性、消耗与数值是 demo 参数，不作为已确认的完整游戏规则。

布局参数、人物资料、行动效果和对话内容应能独立调整。等第二个行动或人物真正复用时，再提取共用结构；不提前建通用编辑器或大型框架。

## 已确认支线方向

### 《两盏茶》

2026-10-04：用户确认将顾青萝／谢长安的情感故事作为一段独立、感人的支线，而不是主线核心谜团。支线采用“结尾重新定义开头”的信息重构：世人误以为顾青萝因谢长安死亡而疯、一生忘不了他；真相是顾青萝早已因“离魂症”逐渐忘记谢长安，谢长安也最终遵守她清醒时的请求，不再要求她记住过去的爱情。谢长安去世后，顾青萝甚至不认识死者，却仍会习惯性地摆出两只茶杯。

该支线的核心意象、客观真相与演出原则见 [历史原稿](../story/sub/tea/README.md)，文件保持原位。A/B 0.1.4 已验收发布；阶段 C 旧院／账册已获本轮实现授权，已通过本机试玩验收，见 [C 任务卡](TEA_C_SLICE.md) 与 [C 验证记录](TEA_C_VALIDATION.md)。进入支线后整条完成前留在其中，阶段完成不返回养成。用户随后授权 D–I 与结尾，当前本机完整评审见 [完整任务卡](TEA_FULL_SLICE.md)；D01 养成保持可用。
