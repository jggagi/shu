## 养成画面的视觉要求

已查看参考截图：中央固定背景，主角与师傅在前景交谈，周边显示人物状态／日期／养成信息，底部承载对话。借鉴的是画面组织和互动感。

- 固定场景作为画面主体；人物、状态和对话随行动更新，师傅互动保持在同一养成场景中。
- 宋式建筑、器物与服饰气质；中国画的留白、山石竹木和克制用色；主角与师傅为有表情的 Q 版人物。
- 信息可读、交互区域明确。面板比例、人物位置、字体大小与色彩细节由 Codex 根据试玩反馈调整，再由用户拍板。
- 后山独立环境实验的晴天加入太阳（2026-10-06 用户要求）；随真实养成时辰呈现位置／暖色变化，太阳构图、大小与当前表现已获用户试玩认可（同日「不错 我喜欢」），不影响养成数值。
- 后山的猫采用与环境、主角统一画风的可爱大橘猫，能够回应玩家互动，也能自己玩（2026-10-06 用户明确要求，D036）。本轮提供点击摸摸与短暂自娱，不影响养成数值；水彩橘猫外形已获用户认可（2026-10-06，D038），具体动作强度与节奏继续按试玩调整。
- 用户提供的三张概念图已原样保存在 [概念图索引](concepts/README.md)。当前按「听雨廊」概念分层制作背景、江砚秋／叶知闲、桌案和纸木面板，运行素材与参考原图分开；原图排除于游戏导出。四个听雨廊角色姿态 PNG 已以原画为底局部合成并接入；具体构图与动态强度继续供试玩评审。

- 听雨廊支持玩家主动开启的环境音及音量控制，先做雨声和与实际落滴同步的檐滴；雨停后渐静，师傅对白时退让，不改变养成数值（2026-10-06 用户同意，D046）。具体音色、音量和参数待试听调整。

- 2026-10-07 用户授权完整听雨廊 P0–P2：统一环境面板、师徒表现、茶气、摸猫、窗景与雨后材质、环境／行动声音、两件案上器物和少量休息文案；所有环境与轻回应不改原养成结算及 Tea 剧情。按授权将两张原角色 PNG 参考图和四个精确提示发送至配置的北京 Qwen 工作空间，完成四次 Qwen Image 3.0 生成且无重试。输出为 RGB，`mentor-listen` 带有烘焙棋盘格；随后使用本地 `tools/compose_tingyu_actors.gd`，仅将姿态区域合入原始 RGBA 角色图。四张 1086×1448 PNG 的 alpha 与原图逐像素一致，合成多边形范围外像素保持原样。Godot 导入及原生四姿态预览通过；Web 与 Windows 包均导出成功，Web 鼠标行动和键盘天气／动静已复核，控制台无警告／错误。Windows 实机、设备听感和用户试玩仍待完成。没有改养成结算或 Tea 剧情。见 D047 与 [完整实施记录](TINGYU_COMPLETE_SLICE.md)。

## 人物表现与场景视觉统一（客户端日期 2026-10-23）

用户确认：蜀山室内养成、日常互动与对白场景统一使用 2D 人物，与同场景的师徒原画保持画风、比例和用色一致。3D 人物模型仅用于练习武功、战斗等动作场景；不把 3D 模型静态渲染帧混入室内 2D 人物群像。同一角色在两种表现中保持身份、服饰与配色对应。

本条明确场景分工：此前 2D 动作路线与后续固定模型制作记录保留为历史，不将练武模型路线扩展为全场景人物替换。当前听雨廊工具试样沿用江砚秋、叶知闲现有 2D 原画，五套剑法继续沿用已获认可的模型与暖色基准。

## 首场景需要支持的复用方向

先用一个场景检验：行动选择、短对话、时间与养成状态的可见反馈。具体属性、消耗与数值是 demo 参数，不作为已确认的完整游戏规则。

布局参数、人物资料、行动效果和对话内容应能独立调整。等第二个行动或人物真正复用时，再提取共用结构；不提前建通用编辑器或大型框架。

### 《两盏茶》

该支线的核心意象、客观真相与演出原则见 [历史原稿](../story/sub/tea/README.md)，文件保持原位。A/B 0.1.4 已验收发布；阶段 C 旧院／账册已获本轮实现授权，已通过本机试玩验收，见 [C 任务卡](TEA_C_SLICE.md) 与 [C 验证记录](TEA_C_VALIDATION.md)。进入支线后整条完成前留在其中，阶段完成不返回养成。用户随后授权 D–I 与结尾，当前本机完整评审见 [完整任务卡](TEA_FULL_SLICE.md)；D01 养成保持可用。
