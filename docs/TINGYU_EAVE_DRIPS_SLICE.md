# 听雨廊：檐下落滴与雨后余水

客户端日期 2026-10-06。用户同意“雨中偶尔落下几滴，雨停后还有短暂余滴”的下一切片。本地分支延续 `codex/tingyu-ambient-life-v1`，保留此前认可的猫比例／案几位置与阵风表现。

## 目标与实现

- 窗外两个既有细雨区域保留；原来的第三片连续檐雨线替换为独立的三处积水落滴。
- 三个落点由听雨廊自身绘画的窗洞上沿定位：场景坐标 `(561,78)`、`(630,33)`、`(725,32)`。在节点排序与窗口 mask 下，水滴留在人物后方及窗外，不落到 HUD 或对白。
- `weather.gd` 读取 EnvironmentPresenter 连续 `rain_amount` 积累小水珠，满后释放短滴，下一轮收集时长用独立固定 seed 调整。它属于可重置的呈现历史，不写 DemoState。
- 雨停时依据已积水量保留有限余滴。常规雨线在既有过渡中先退去，三个落点在约 2.8／4.6／6.4 秒依次释放余水，随后消失；没有雨水积累的干燥切换不制造余滴。
- Static 保留当前积水／落滴并冻结其 elapsed；Dynamic 原位继续。静态下天气与时辰仍可按既有合同过渡。Reset 清空积水、下落与余滴。师傅 Busy 中水滴降低对比，短滴自然完成。

参数位于 `assets/data/tingyu_environment.json` 的 `eave_drips`：雨中初次收集参数 2.6／4.8／7.3 秒，后续单落点 6–10 秒，受连续雨量影响；落滴约 1 秒。它们是可调制作参数，不是永久规格。新着色器 `assets/shaders/eave_drips.gdshader` 画小水珠与短滴，全部 timing 在 adapter；不使用 TIME 或逐帧随机。
