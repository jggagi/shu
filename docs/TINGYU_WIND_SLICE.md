# 听雨廊：一阵风经过

客户端日期 2026-10-06。用户要求留在听雨廊让环境更生动，并同意先做“一阵风经过”。本轮复用现有 `weather.gd`、竹叶图层与背景中一个真实帘穗，不生成新美术、不改玩法状态。

## 玩家可观察的目标

- 平时竹叶比原先更安静；一阵风先带动竹叶，再带动帘穗，随后缓慢回到平静。
- 风力读取当前 EnvironmentPresenter 的晴／多云／小雨连续参数；晴天轻，雨天稍强，不建立第二套天气或玩法时钟。
- 宿主忙碌门直接读取修炼、师傅对白、结果等待与 Tea 状态。Busy 不开始新阵风，已有风平滑收敛。
- Static 冻结环境 elapsed 与阵风位移，保留竹叶和帘穗；Dynamic 从当前姿态继续，重置恢复固定种子调度。

## 当前制作参数

`assets/data/tingyu_environment.json` 的 `wind_moments` 为本场景可调参数：初次等待 8 秒、阵风持续 7 秒、结束后等待 22–34 秒、帘穗滞后 0.65 秒。背景帘穗按源纹理坐标局部形变，角色和案几的材质默认关闭此效果。帘穗根部保持附着，不新增重影图层。

## Skill 与边界

主流程使用 `game-painted-scene-build`，着色器小任务按 `tiered-coding` 委派真实 Luna worker，根代理负责节奏、宿主连接与画面审阅。本轮没有生成 raster art，未进入 `game-art` 的付费生产流程；现有 skill 足够，不修改 skill 或提取 addon。

## 画面与交付记录

Godot 4.7.2 / Apple M4 / Compatibility 实际窗口已完成晴／雨的风过程捕获，以及真实师傅 Busy、首轮机会 Busy、Static 峰值冻结与 Dynamic 原位恢复的预览；启动与渲染日志无报错。人工查看完整画面和放大帘穗局部：竹叶回摆明显，猫／人物／UI 未随阵风形变。帘穗上部被已有任务牌遮挡，露出的下半段为轻微次级响应，待玩家判断是否足够可见；源图横向形变区域留出最大侧移的边距，避免重影。
