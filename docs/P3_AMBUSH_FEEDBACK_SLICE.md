## 反馈来源与本轮目标

用户在原模型复用后反馈「不错，下面做什么」，随后对继续本关打磨战斗反馈的建议回复「好」。据此批准本片范围：动作衔接、命中与受击、击退碰撞／打断、敌方攻击范围和药篓危机提示。实施授权、代码完成、实际检查与用户观感分别记录；本轮检查已完成，用户对新效果的认可仍待试玩。

保持江砚秋、沈听岚对三名来敌的同一遭遇，目标是让玩家在正常战场画面里看清「谁出了什么招、敌人为何改变位置或停手、下一轮哪里危险、药篓还能承受多少威胁」，减少必须翻战报才能理解行动后果的情况。

| 本轮范围 | 玩家可观察的变化目标 |
| --- | --- |
| 动作衔接 | 移动到位、出招、命中、受击和收势先后清楚；人物、脚点和武器连续，结束回到稳定待机。 |
| 击退与碰撞 | 击退路径、实际落点与撞障反馈对应规则结果；额外碰撞伤害只在规则回执确有该结果时展示。 |
| 打断 | 玩家出招命中后能看清来敌本轮被打断，其取消的蓄势和攻击区域同步变化。 |
| 敌方攻击范围 | 从真实当前行动计划显示敌人将影响的格子与目标；移动、击退或打断后的变化可读，不能把装饰范围当成隐藏规则。 |
| 药篓危机 | 现有HP、当前已知威胁与实际受损有清楚对应；危险提示来自真实计划，不凭表现层另算伤害或决定胜败。 |

## 验收卡

1. 实际走完移动→出招→命中→受击→收势，查看正常速度下的脚底、武器与身体衔接；完成后人物稳定待机，不能停留在受击或攻击末姿。
2. 分别触发自由击退、撞障／边界和打断。核对真实位置、实际伤害、取消行动及表现文字一致；无碰撞或无打断时不误播对应反馈。
3. 在选择招式、预览目标、移动、击退和打断前后，对照当前真实计划检查高亮格、目标和威胁提示；取消选择后恢复应有显示。
4. 实际观察药篓安全、受到威胁、受损和失守的状态，确认危机提示、HP与胜败对应。不能因特效重复播放而重复扣血。
5. 打开并关闭近看，再继续动作；检查弹层输入隔离、旧回调失效与原战局保持。完成胜败、战中重开／终局重试、返回城镇、返山和同场师父选择。
6. 对照本片修改前的受保护规则、Session、存档与遭遇数据；分别记录规则／会话检查、两种既有窗口尺寸的原生画面和输入、导出包回归及浏览器结果。用户实际观感另行记录。
